# Karanam Kartikeya | Personal Profile Page

A personal profile page built with HTML and CSS and hosted on GitHub Pages. It covers who I am, my education, projects, skills, interests and how to reach me.

**Live site:** https://kartikeyakaranam.github.io/Profile-Page/

## What's on the page

- Profile photo and short introduction
- About me
- Education
- Projects
- Skills
- Interests
- Contact and social links

## Built with

- HTML for the structure
- CSS for the layout, colours, fonts and spacing
- Flexbox, CSS Grid and media queries so it works on phones and laptops
- Google Fonts (Bricolage Grotesque and DM Sans)

## Files

```
├── index.html
├── style.css
└── images/
    └── profile.jpg
```

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any browser.
